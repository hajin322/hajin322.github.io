Observation to Prediction through Estimation

From the past as observation to the future as prediction, through estimation.

관측으로서의 과거에서, 추정을 거쳐, 예측으로서의 미래로.

From past observations, what should we estimate, and what future does that estimate predict? Each section puts the three in one frame. A 1/0 signal and a person climbing a staircase serve as examples, so the graphs can be read intuitively.

과거의 관측으로 무엇을 추정해야 하고, 그 추정으로 어떤 미래를 예측하는가. 각 절은 이 셋을 한 프레임에 담는다. 1/0 신호와 계단을 오르는 사람을 예로 들어 그래프를 직관적으로 읽을 수 있게 했다.

01 Binomial

Observation

n0
s0
n − s0
s / n–

Estimation

f(p) ∝ ps(1 − p)n−s  →  Beta(s + 1, n − s + 1)

Prediction

P(S = j) = C(m, j) pj(1 − p)m−j

Success rate

A run with s successes and n − s fails has probability

성공 s번, 실패 n − s번이 나올 확률은

p · p ⋯ p · (1 − p) ⋯ (1 − p) = ps(1 − p)n−s,

and read as a function of p, this is the shape of the estimate.

이고, 이를 p의 함수로 보면 그대로 추정의 모양이 된다.

Success event

Any one order of j successes and m − j fails has probability pj(1 − p)m−j, and there are C(m, j) ways to choose which trials succeed. So

성공 j번과 실패 m − j번의 순서 하나의 확률은 pj(1 − p)m−j이고, m번 중 어느 시행이 성공할지 고르는 방법이 C(m, j)가지다. 따라서

P(S = j) = C(m, j) pj(1 − p)m−j.

Binomial(n, p)⟶Poisson(λ)   as  n → ∞,  np = λ

Let the number of trials n grow without bound while the success rate p shrinks, so that their product stays fixed. The binomial then becomes the Poisson, and the speed λ is that product np. In this limit single 1/0 trials can no longer be observed, so the observation becomes a count over time. (With p held fixed instead, the binomial tends to a Gaussian.)

시행 횟수 n을 무한히 늘리면서 성공률 p를 줄여 둘의 곱을 일정하게 두면, 이항분포는 포아송 분포가 되고 속도 λ는 그 곱 np이다. 이 극한에서는 1/0 시행 하나하나를 관측할 수 없으므로, 관측은 시간당 개수로 바뀐다. (p를 고정한 채 n만 늘리면 이항분포는 가우시안에 가까워진다.)

02 Poisson

Observation

t0.0
N(t)0
N(t) / t–
w–

Estimation

f(λ) ∝ λN e−λt  →  Gamma(N + 1, t)

Prediction

P(N = k) = (λt)k e−λt / k!

f(w) = λkwk−1e−λw / (k − 1)!

Speed

Cut the t seconds into n slices of width Δ = t / n. A slice climbs at most one step, so its mean number of steps, p = λΔ = λt / n, is also the probability that it climbs. N steps in n slices then have probability

t초를 폭 Δ = t / n인 조각 n개로 쪼갠다. 조각 하나는 최대 한 칸만 오르므로, 조각의 평균 칸 수 p = λΔ = λt / n가 곧 한 칸 오를 확률이다. n개 조각에서 N칸 오를 확률은

pN(1 − p)n−N= ΔN · λN · (1 − λt / n)n−N.

As n → ∞, ΔN does not depend on λ and cancels when the estimate is normalized, while (1 − λt / n)n−N → e−λt. So

n → ∞이면 ΔN은 λ와 무관해 추정을 정규화할 때 약분되고, (1 − λt / n)n−N → e−λt이다. 따라서

f(λ) ∝ λN e−λt.

Number of counts

With the same slices, k steps in n slices is a binomial count:

같은 조각으로 보면, n개 조각에서 k칸 오르는 것은 이항 개수다.

P(N = k) = C(n, k) (λt / n)k (1 − λt / n)n−k

As n → ∞, C(n, k) / nk → 1 / k! and (1 − λt / n)n−k → e−λt, so

n → ∞이면 C(n, k) / nk → 1 / k!, (1 − λt / n)n−k → e−λt이므로

P(N = k) = (λt)k e−λt / k!

Waiting time

The k-th step lands in [w, w + dw) exactly when k − 1 steps happen before w and one happens in dw:

k번째 칸이 [w, w + dw)에 오르는 것은 w 전까지 k − 1칸을 오르고 dw 안에서 한 칸을 오를 때다.

f(w) dw = (λw)k−1e−λw / (k − 1)! · λ dw

So f(w) = λkwk−1e−λw / (k − 1)!, and k = 1 gives λe−λw.

따라서 f(w) = λkwk−1e−λw / (k − 1)!이고, k = 1이면 λe−λw이다.
