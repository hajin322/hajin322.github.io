Learning Framework

Decision making is the process of making choices. An agent interacts with an unknown environment: at each round t it receives a context xt, makes a decision πt, and in return receives a reward rt and an observation ot. The crux of the problem is to explore the environment to reduce uncertainty while maximizing overall performance. The learning objective is for the agent to learn a good mapping xt ↦ πt, from contexts to decisions.

의사결정은 선택을 내리는 과정이다. 에이전트는 알려지지 않은 환경과 상호작용한다. 매 라운드 t마다 맥락 xt를 받고, 결정 πt를 내리고, 그 대가로 보상 rt와 관측 ot를 받는다. 문제의 핵심은 환경을 탐색해 불확실성을 줄이면서 전체 성능을 최대화하는 것이다. 학습 목표는 맥락에서 결정으로 가는 좋은 사상 xt ↦ πt를 배우는 것이다.

Every problem reflects this decision-making frame.

모든 문제는 이 의사결정 프레임을 반영한다.

A decision-making problem is divided by seven factors: data acquisition, decision structure, temporal structure, reward model, feedback, learning objective, and environmental model.

의사결정 문제는 일곱 개의 요소로 나뉜다: 데이터 획득, 결정 구조, 시간 구조, 보상 모델, 피드백, 학습 목표, 환경 모델.
